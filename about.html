About Resources

A curated fashion archive for mood-based styling inspiration

Project Overview

This website is a fashion resource archive that gathers outfit references, styling inspiration, and fashion magazine materials in one place. The goal of this project is to help users explore different moods, aesthetics, and outfit combinations through a visually curated platform.

Concept

Rather than functioning as an online store, this site acts as a visual research tool. Users can browse outfits, discover styling ideas, and explore fashion imagery based on mood and aesthetic direction.

Sources & Materials

The current version of this project was developed using resources collected from online platforms.

  • Outfit images: Pinterest
  • Fashion magazine archive: Internet Archive

All materials are used for educational and research purposes as part of this academic project.

Purpose

This resource explores how digital platforms can organize visual inspiration and support personal styling exploration. It also reflects an interest in fashion archiving, image curation, and interface design.
